# Font Licenses

This directory contains font files used in the project.
Each font must have its license verified and documented in manifest.json.

## Required Fonts (from manifest.json)

| Font | Source | License | License URL |
|------|--------|---------|-------------|
| Satoshi Bold | fontshare.com | ITF Free | https://www.fontshare.com/license |
| Satoshi Regular | fontshare.com | ITF Free | https://www.fontshare.com/license |
| Inter Bold | github.com/rsms/inter | OFL | https://scripts.sil.org/OFL |
| Inter Regular | github.com/rsms/inter | OFL | https://scripts.sil.org/OFL |
| Inter Light | github.com/rsms/inter | OFL | https://scripts.sil.org/OFL |
| Caveat Brush Regular | fonts.google.com | OFL | https://scripts.sil.org/OFL |

## Adding New Fonts

1. Download .woff2 or .ttf file
2. Place in this directory
3. Add entry to manifest.json with:
   - path, name, source URL
   - license type (OFL, ITF Free, MIT, etc.)
   - license URL
   - author
   - use: "final" or "reference-only"
4. Run `python scripts/fetch_assets.py --category fonts`
5. Update src/data.js fontFamilies if needed

## License Compliance

- **OFL (Open Font License):** Free for commercial use, cannot sell font alone
- **ITF Free (Indian Type Foundry):** Free for commercial use, see fontshare.com/license
- **MIT:** Free for commercial use with attribution
- **Custom:** Verify terms before use

**Never commit a font without verified license in manifest.json.**
